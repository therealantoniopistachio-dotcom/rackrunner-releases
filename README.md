# RackRunner

Android test build. Not on the Play Store yet, so installing takes a minute.

## Install

1. Download the newest APK:
   https://github.com/therealantoniopistachio-dotcom/rackrunner-releases/releases/latest
   Tap the file ending in `.apk` under Assets. Ignore the "Source code" files.
2. Chrome warns that this kind of file can be harmful. Tap **Download anyway**.
3. Open the file. If asked, allow installs from this app.
4. Play Protect may say the app is unrecognized or blocked. Tap
   **More details → Install anyway**. The app asks for only two permissions,
   internet and network status, and is signed by the developer.

## First time

1. Open RackRunner → **Account**.
2. Paste this server address and tap **Connect**:
   `https://rackrunner-backend-production.up.railway.app`
3. Tap **Create account** using the email address you were invited with,
   and a password of six or more characters.

## Using it

Shoot the tag, shoot the item, tap **Scan item**, and keep moving — each item
prices while you shoot the next. A **Price** tile takes the price sticker, or
type what you paid. Green means buy, yellow means maybe, grey means pass, red
means a possible rare find.

**When a price looks wrong, tap "Price looks wrong?" and enter what the sold
comps actually say.** That's the most useful thing you can send back.

## Updating

The app tells you when a new version is available and links here. Install it
straight over the old one — your history and sign-in are kept.
Always install the newest version. Installing an older one over a newer one
triggers a security warning from Android.
